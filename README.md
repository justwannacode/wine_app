# ММАД ДЗ-3

Streamlit-приложение для отбора хороших вин моделью логистической регрессии из ДЗ-3.

## Запуск

Python **3.13**.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на http://localhost:8501. Рядом с `app.py` должны лежать `model.joblib`, `config.json` и `test.csv`, сохранённые в ноутбуке.

## Вкладки

- **Оценка вина** - ввод 12 признаков, вероятность и решение при пороге из сайдбара.
- **Метрики** - матрица ошибок, precision / recall / F1, ROC- и PR-кривые с точкой текущего порога.
- **Предсказание** - загрузка CSV, таблица с вероятностями и решениями, скачивание результата.
- **Что выучила модель** - коэффициенты логистической регрессии.

## Кэширование

- `st.cache_resource` хранит один общий объект без копирования и сериализации - подходит для модели: она не меняется и не должна копироваться при каждом перезапуске скрипта.
- `st.cache_data` хранит сериализованный результат и отдаёт каждому вызову копию - подходит для данных (таблицы, массивы вероятностей): если код случайно изменит DataFrame, кэш не испортится.
